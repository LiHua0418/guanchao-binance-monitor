# B4 训练与本地面板交付记录

2026-10-08。原 B3 保留作对照，新增的树模型方向、幅度和均值推理命名为 `guanchao-b4`，界面明确标为实验版。所有改动与模型保存在本地仓库，尚未提交或推送 GitHub。

## 本轮结果

冻结公共行情共 347,681 根，四币种合计 339,044 个起点。每周期各自学习 12 个均值输出、12 个幅度输出和 4 个方向输出。下一根绝对变化幅度相对过去 20 根平均绝对收益的历史复评改善如下：

| 周期 | 幅度 MSE 降低 | 幅度 MAE 降低 | 方向平衡准确率 | 前一根反转方向基线 |
|---|---:|---:|---:|---:|
| 15min | 9.45% | 4.03% | 52.06% | 51.13% |
| 1h | 9.74% | 3.45% | 52.76% | 52.41% |
| 4h | 8.02% | 3.07% | 52.36% | 53.35% |
| 1d | 7.59% | 1.47% | 50.00% | 50.75% |

这不是带方向的价格预测误差下降，也不是上涨胜率。日线 MAE 改善的时间块置信区间跨零，只有 197 个独立时点，因此不标为已通过全部验证。完整价格均值路径没有稳定超越持平的证据。4h、1d 部分较远步数还差于基线。近期留出时段此前已查看，不能称为新增未见的未来测试。

另完成四周期、每周期两个固定初始种子的 113,433 参数 TCN–Attention 网络：CPU 6 线程总约 28.10 分钟。其价格预测未胜持平，未替换面板。独立 CUDA 环境 RTX 5070 已通过真实训练路径 smoke 和权重重载；同批训练微基准 GPU 22,733 样本/秒、CPU 6 线程 2,354 样本/秒，约 9.66 倍。不是全流程加速倍数，现有正式权重仍来自 CPU 多线程训练。

## 面板

- B4 默认显示，保留 B3 对照按钮。
- 未来每根一个模型点；15min、1h、4h、1d 分别按自己的周期递增。
- 历史紫点始终是“上一根收盘时预测下一根”，最多 240 点，排除拟合与校准时段。
- 蓝线保留真实均值，绿色上下行情景来自独立绝对幅度模型；不伪造价格波动，不把情景称为置信区间。
- +1/+3/+6/+12 有独立上涨概率；其他步不插值，显示空缺。
- REST/WebSocket 提供成交笔数与主动买入信息。未闭合 bar 不改变预测；缺数据或不支持的交易对不沿用旧预测。
- `npm run dev` / `npm run preview` 启动或复用回环地址的本地服务；单独服务命令 `npm run model:serve`。

## 验证

前端测试覆盖四周期时间步长、请求切换/取消/延迟回复、闭合后刷新、历史更正重算、严格服务契约、真实组件 SSR 的概率与幅度口径。11 项 Python 真实模型/HTTP 测试验证四周期、输入拒绝、回放起点、缓存和因果性。生产 build 与 lint 通过。

独立复核：四周期同一起点给最后 100/200/500/1000 根数据，12 步价格最大差不超过 2.91e-11、方向概率差为 0；校准截止的首个回放点精确对应此前该起点的 h1 预测。

实页检查四周期、B3/B4 切换、XRP 未支持状态、恢复 BTC 1h，浏览器控制台无错误。截图在 `.cache/qa/b4-trained-panel.jpg`。当前本地服务地址为 `http://127.0.0.1:8765`，面板地址为 `http://127.0.0.1:5173`。
